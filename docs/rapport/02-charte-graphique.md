## 1. Identité visuelle

Traiteur événementiel bordelais : ton **gourmand**, chaleureux, lisible (mobile first).

### Palette (CSS `:root`)

| Token | Couleur | Usage |
|-------|---------|--------|
| `--primary` | `#8b1c1c` | Titres, logo, accents bordeaux |
| `--primary-light` | `#b32424` | Survol / variantes |
| `--secondary` | `#d4af37` | Or — CTA, titres footer |
| `--bg-light` | `#fbfbfb` | Fond de page |
| `--text-main` | `#333333` | Texte courant |
| `--text-muted` | `#666666` | Texte secondaire |
| Footer | `#222222` | Pied de page |

### Typographie

| Usage | Police |
|-------|--------|
| Interface | `Segoe UI`, Tahoma, Geneva, Verdana, sans-serif |
| Titres marque | Style serif / emphase via CSS existant (logo navbar) |
